# phatbeast
A Pi Playlist Player using MPD, MPC and Python with Flask and Tornado. <br> 
Install Dietpi Os and the following software:  <img width="947" height="347" alt="dietpisoftware" src="https://github.com/user-attachments/assets/32906329-2cc3-4f2e-be27-ef3694c43ac3" /> <br>
Well, Squeezelite, Dietpi Dashboard, RPI Monitor and Wiring Pi may be overkill, but at least use Nginx, MPD (don't forget to install MPC afterwards from command line), Alsa, and the Python libraries. <br>
