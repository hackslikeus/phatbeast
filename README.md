# phatbeast
A Pi Playlist Player using MPD, MPC and Python with Flask and Tornado. <br> 
Install Dietpi Os and the following software:  <img width="947" height="347" alt="dietpisoftware" src="https://github.com/user-attachments/assets/32906329-2cc3-4f2e-be27-ef3694c43ac3" /> <br>
Well, Squeezelite, Dietpi Dashboard, RPI Monitor and Wiring Pi may be overkill, but at least use Nginx, MPD (don't forget to install MPC afterwards from command line), Alsa, and the Python libraries. <br>
<img width="810" height="809" alt="responsive" src="https://github.com/user-attachments/assets/3374894b-44ff-43dc-b727-9f859d7b4119" /> <br>
Tested on both Dietpi and Raspberry pi OS. Will work on both platforms, but if you are using additional clients, such as squeezelite or another MPD client, use Dietpi as you will find resource conflicts and slower boot times with Raspberry Pi OS.  If you have a large music collection, use a database backend such as SQL lite, or Maria DB.<br>
No need to git clone, just copy the .py file to a local folder and run from there.
